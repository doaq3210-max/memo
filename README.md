# 메모장

Supabase를 백엔드로 사용하는 단일 페이지(`index.html`) 메모장 웹사이트입니다.

## 기능

- 메모 작성 후 **추가** 버튼으로 저장
- 저장된 메모는 **최신순**으로 정렬되어 표시
- **수정** 버튼으로 메모 내용 변경
- **삭제** 버튼(확인 후) 으로 메모 삭제
- 노션(Notion) 스타일의 미니멀한 디자인

## 사용 방법

1. `index.html` 파일을 브라우저로 열기만 하면 바로 사용할 수 있습니다. (별도 서버, 빌드 과정 필요 없음)
2. Supabase 프로젝트 URL과 anon(공개) 키가 코드에 이미 포함되어 있어 추가 설정이 필요 없습니다.

## Supabase 구성

- **프로젝트**: `Sungwoo's Project` (`msmwnaksuegjgeutepcc`, 리전: `ap-northeast-2`)
- **테이블**: `public.memos`
  | 컬럼 | 타입 | 설명 |
  | --- | --- | --- |
  | `id` | `uuid` (PK, 기본값 `gen_random_uuid()`) | 메모 고유 ID |
  | `content` | `text` | 메모 내용 |
  | `created_at` | `timestamptz` (기본값 `now()`) | 작성 시간 |

- **RLS(Row Level Security)**: 활성화되어 있으며, `anon` 역할에 대해 `select` / `insert` / `update` / `delete`를 모두 허용하는 정책을 적용했습니다. 즉 **누구나 별도 로그인 없이 메모를 읽고, 쓰고, 수정하고, 삭제**할 수 있습니다.

> ⚠️ 참고: 인증 없이 모든 사용자가 쓰기/삭제까지 가능한 설정이므로, 실제 서비스로 운영할 경우 스팸이나 악의적인 삭제에 취약할 수 있습니다. 필요하다면 이후에 Supabase Auth 및 정책을 추가해 접근을 제한할 수 있습니다.

## 데모 테스트

배포 직후 브라우저 자동화로 메모 3개를 직접 입력하여 저장 → 목록에 최신순으로 표시되는지 확인했습니다.
